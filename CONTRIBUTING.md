# Contributing to Aqwam

Thank you for helping. This project is done for the sake of Allah: free, no ads, no tracking.

## How it works
1. Fork the repository and create a branch from `main`.
2. Make a small, focused change and open a Pull Request.
3. Nothing is merged without the owner's approval.
4. Contributors are credited in the repository (Contributors page and CONTRIBUTORS file).

## Code
- Follow the rules in `AGENTS.md` (architecture, design tokens, localization, tests).
- Every change needs tests, and CI must pass.

## Religious content (Quran, hadith, adhkar, tafsir)
- Content changes MUST cite a verified source and its license.
- Never type religious text from memory. Never edit content data files by hand.
- Content PRs get extra review from the owner.
